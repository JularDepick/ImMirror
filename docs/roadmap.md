# 里程碑

里程碑描述项目的功能推进单元。状态按各仓库代码与用例的实际内容判定, 不设时间承诺, 也不以口头结论代替代码。

## 二、逐项验收标准

### M0 规划与仓库骨架

- 四个仓库相互独立, 各自维护根级忽略规则
- 仓库一级目录与各仓库 README 齐备
- 项目文档覆盖需求, 架构, 素材, 里程碑, 决策与环境

### M1 服务端账号域

- 注册需要邮箱与验证码, 成功后返回 UID 与令牌
- 登录支持邮箱或 UID 加密码, 以及邮箱加验证码两种方式
- 找回密码通过邮箱验证码完成, 重置后旧密码失效
- 换绑邮箱需要验证新邮箱并二次确认密码
- 会话在登出后立即失效, 过期会话返回明确错误码
- 接口用例覆盖注册, 登录, 重置, 换绑, 会话与通用约定
- 任意路径都返回 JSON, 不出现 HTML

### M2 服务端货币签到

- 钱包余额与变动流水可查询, 余额不为负
- 同一自然日重复签到返回冲突错误
- 当月签到次数跨月清零, 里程碑奖励单独记流水
- 签到插入与余额更新在同一事务内完成

### M3 客户端工程骨架

- 外置脚本一次产出三个 ABI 的原生库
- 安装包可安装, 可启动, 可退出
- 启动界面展示设备分级结果
- 游戏界面进入原生主循环, 帧率日志按固定帧数输出
- 前后台切换后渲染恢复且不崩溃

### M4 体素垂直切片

- 地形可见起伏的山体与地表
- 邻近区块之间不出现接缝与内部面
- 方块贴图经图集合成后正确显示
- 左半屏摇杆移动, 右半屏拖动转视角, 重力与落地正常
- 准星命中方块可破坏, 长按可在命中面外放置
- 走出视距时区块加载, 离开后卸载

### M5 存档与设备分级

- 世界写入存档后可完整读回, 方块与玩家位姿一致
- 定时自动落盘, 前后台切换与退出时落盘
- 设备分级映射到不同视距档位
- 破坏与放置触发对应音效, 音频输出不阻塞主线程

### M6 账号界面与联调

- 登录, 注册, 找回密码三种表单可在同一页切换
- 验证码按钮带倒计时, 错误按错误码映射为中文提示
- 服务端地址可在界面内修改并即时生效
- 登录成功后进入游戏, 从游戏返回后展示账号资料与余额
- 待补: 换绑邮箱界面, 签到界面, 主菜单与设置

### M7 脚本 DSL 运行时

- 自有语法的脚本可编译为字节码并由虚拟机执行
- 触发器与组件行为由脚本驱动
- 单脚本指令预算, 内存配额与执行超时生效
- 脚本无法访问文件与网络

### M8 UGC 编辑器

- 触发器编辑, 组件编辑与属性面板可用
- 编辑结果可在体素预览中查看
- 编辑器与游戏运行时的数据格式一致

### M9 联机

- 可创建与加入房间
- 房间内玩家位置与方块变更同步
- 断线后可重连并恢复状态

### M10 发布工程

- 素材管线覆盖全部随包资源
- 安装包使用新密钥对签名, 同时启用 V1, V2 与 V3
- 发布安装包可旁加载安装并正常启动

## 三、状态口径

| 状态 | 判定标准 |
|:---:|:---:|
| 已完成 | 目标功能在代码中可查, 验收项在构建或运行中可复现 |
| 进行中 | 部分功能已落地, 验收项尚未全部满足 |
| 未开始 | 仓库内没有对应实现 |

状态随代码变化更新, 与提交记录保持一致; 里程碑顺序遵循先服务端后客户端的需求约束 (R13)。
